# Car Price Category API (FastAPI)

REST-сервис на FastAPI, который предсказывает ценовую категорию автомобиля (`low`, `medium`, `high`) по данным объявления. Внутри сериализованный sklearn-пайплайн: предобработка, генерация признаков и лучшая из трёх моделей, выбранная по кросс-валидации.

Учебный проект: разработка ML-сервиса от обучения пайплайна до API.

## Эндпоинты

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/status` | Проверка работоспособности, возвращает `"I’m OK"` |
| GET | `/version` | Метаданные модели: название, автор, версия, дата, тип алгоритма, accuracy на кросс-валидации |
| POST | `/prediction` | Принимает JSON с данными автомобиля, возвращает предсказанную категорию цены |

Интерактивная документация (Swagger) доступна по адресу `/docs`.

### Пример запроса

В теле обязательны только `id` и `price`, остальные поля необязательные. Поле `price` моделью не используется (оно отбрасывается на этапе фильтрации) и просто возвращается в ответе.

```json
{
  "id": 1,
  "region": "example-region",
  "price": 10000,
  "year": 2015,
  "manufacturer": "ford",
  "model": "f-150",
  "condition": "excellent",
  "cylinders": "6 cylinders",
  "fuel": "gas",
  "odometer": 15000,
  "title_status": "clean",
  "transmission": "automatic",
  "drive": "4wd",
  "size": "full-size",
  "type": "truck",
  "paint_color": "white",
  "state": "tx"
}
```

### Пример ответа

```json
{
  "id": 1,
  "pred": "medium",
  "price": 10000
}
```

## Как устроен пайплайн (`pipeline.py`)

1. **Фильтрация колонок:** удаляются неинформативные и потенциально утечные признаки (`id`, `url`, `region`, `region_url`, `price`, `manufacturer`, `image_url`, `description`, `posting_date`, `lat`, `long`).
2. **Выбросы:** значения `year` за границами IQR (1,5 × межквартильный размах) обрезаются до границ.
3. **Новые признаки:** `short_model` (первое слово названия модели) и `age_category` (`new` — после 2013, `old` — до 2006, иначе `average`).
4. **Обработка типов:** числовые признаки — заполнение медианой и `StandardScaler`; категориальные — заполнение самым частым значением и `OneHotEncoder`.
5. **Выбор модели:** сравниваются `LogisticRegression`, `RandomForestClassifier` и `SVC` по accuracy на кросс-валидации (cv=4). Лучшая модель обучается на всём датасете и сохраняется через `dill` вместе с метаданными.

## Структура репозитория

- `main.py` — FastAPI-сервис (эндпоинты, Pydantic-модели, загрузка модели при старте).
- `pipeline.py` — обучение и сериализация пайплайна.
- `model/cars_pipe.pkl` — обученный пайплайн с метаданными (в репозитории отсутствует, создаётся запуском `pipeline.py`).
- `data/` — папка для вашего датасета (в репозитории отсутствует).

## Данные и модель

Датасет и обученная модель в репозиторий не входят: данные получены в рамках учебного курса и распространению не подлежат. Модель `SVC` хранит опорные векторы, то есть фактически фрагменты обучающей выборки, поэтому `.pkl` тоже не публикуется. Папки `data/` и `model/` добавлены в `.gitignore`.

Для обучения нужен CSV с признаками объявлений о продаже автомобилей (колонки как в схеме `CarForm` в `main.py`) и целевой колонкой `price_category` (`low`, `medium`, `high`).

## Запуск

```bash
git clone https://github.com/etl-and-pray/ds-intro-fast-api.git
cd ds-intro-fast-api
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install fastapi uvicorn pandas "scikit-learn>=1.2" dill pydantic

# 1. положите свой датасет в data/homework.csv и обучите модель
python pipeline.py               # создаст model/cars_pipe.pkl

# 2. запустите сервис
uvicorn main:app --reload
```

Скрипт обучения выведет accuracy каждой модели и сохранит лучшую в `model/cars_pipe.pkl`. Сервис поднимется на `http://127.0.0.1:8000`. Проверка:

```bash
curl http://127.0.0.1:8000/status
curl http://127.0.0.1:8000/version
```

Без файла модели `/status` отвечает, а `/version` и `/prediction` возвращают ошибку 500.

## Ограничения

- Accuracy в `/version` — это средний результат кросс-валидации, по которому выбиралась модель, а не оценка на отдельной отложенной выборке.
- Модель сохранена через `dill` и привязана к версиям библиотек. Если `/prediction` падает при загрузке, попробуйте поставить ту же версию `scikit-learn`, что использовалась при обучении, и не открывайте чужие `.pkl`: десериализация может выполнить произвольный код.
- В сервисе нет аутентификации, тестов, логирования и контейнеризации — проект учебный.
